# Skraćenice

| Skraćenica | Pun naziv (eng.)                                                     | Objašnjenje                                                                                                |
| ---------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| ACID       | Atomicity, Consistency, Isolation, Durability                        | Svojstva transakcija u bazi podataka: nedeljivost, konzistentnost, izolacija i trajnost                    |
| API        | Application Programming Interface                                    | Programski interfejs preko koga softverske komponente komuniciraju; ovde REST interfejs servera            |
| CI         | Continuous Integration | Kontinuirana integracija: automatska izgradnja i provera koda pri svakoj izmeni |
| CNG        | Continuous Native Generation                                         | Expo pristup u kome se nativni projekti za iOS i Android generišu iz konfiguracije                         |
| CORS       | Cross-Origin Resource Sharing                                        | Mehanizam kojim server pretraživaču saopštava kojim drugim poreklima (adresama) dozvoljava pristup API-ju |
| CSS        | Cascading Style Sheets                                               | Jezik za opis izgleda web stranica                                                                         |
| DASH       | Dynamic Adaptive Streaming over HTTP                                 | Protokol za adaptivnu isporuku video snimaka preko HTTP-a                                                  |
| DMA        | Digital Markets Act                                                  | Zakon Evropske unije o digitalnim tržištima                                                                |
| DOM        | Document Object Model                                                | Objektni model dokumenta: stablo elemenata web stranice kojim upravlja pretraživač                         |
| EAS        | Expo Application Services                                            | Expo servisi za izgradnju, objavljivanje i ažuriranje mobilnih aplikacija                                  |
| ER         | Entity-Relationship                                                  | Model entiteta i veza za opis strukture podataka (P. Chen, 1976)                                         |
| FZ         | — (srp. funkcionalni zahtev)                                         | Oznaka funkcionalnog zahteva u poglavlju 4                                                                 |
| HATEOAS    | Hypermedia as the Engine of Application State                        | REST ograničenje po kome odgovori sadrže veze ka mogućim sledećim akcijama                                 |
| HLS        | HTTP Live Streaming                                                  | Protokol za adaptivnu isporuku video snimaka preko HTTP-a                                                  |
| HMAC       | Hash-based Message Authentication Code                               | Kod za proveru autentičnosti poruke zasnovan na heš funkciji i tajnom ključu                               |
| HTML       | HyperText Markup Language                                            | Jezik za opis strukture web stranica                                                                       |
| HTTP       | HyperText Transfer Protocol                                          | Protokol za prenos podataka na webu                                                                        |
| IEC        | International Electrotechnical Commission                            | Međunarodna organizacija za standarde u elektrotehnici                                                     |
| IEEE       | Institute of Electrical and Electronics Engineers                    | Profesionalna organizacija koja, između ostalog, objavljuje standarde                                      |
| IETF       | Internet Engineering Task Force                                      | Organizacija koja razvija internet standarde (RFC)                                                         |
| ISO        | International Organization for Standardization                       | Međunarodna organizacija za standardizaciju                                                                |
| JSI        | JavaScript Interface                                                 | Sprega u novoj arhitekturi React Native-a za direktne pozive nativnog koda iz JavaScript-a                 |
| JSON       | JavaScript Object Notation                                           | Tekstualni format za razmenu strukturiranih podataka                                                       |
| JSX        | JavaScript XML                                                       | Proširenje sintakse JavaScript-a za opis korisničkog interfejsa u React-u, slično HTML-u                   |
| JWT        | JSON Web Token                                                       | Standard (RFC 7519) za kompaktno prenošenje potpisanih tvrdnji; koristi se kao pristupni token             |
| LMS        | Learning Management System                                           | Sistem za upravljanje učenjem koji koristi obrazovna institucija (npr. Moodle, Canvas)                     |
| LTS        | Long-Term Support                                                    | Verzija softvera sa produženim periodom podrške                                                            |
| MAU        | Monthly Active Users | Broj korisnika aktivnih u toku meseca; jedinica naplate autentifikacije (Supabase) |
| MCP        | Model Context Protocol                                               | Otvoreni protokol preko koga asistenti zasnovani na VI pristupaju alatima i podacima spoljnih sistema      |
| MOOC       | Massive Open Online Course                                           | Masovni otvoreni onlajn kurs (npr. Coursera, edX)                                                          |
| MVP        | Minimum Viable Product                                               | Prva verzija proizvoda sa najmanjim skupom funkcionalnosti potrebnim da se proveri ideja                   |
| NFZ        | — (srp. nefunkcionalni zahtev)                                       | Oznaka nefunkcionalnog zahteva u poglavlju 4                                                               |
| OAuth      | Open Authorization                                                   | Standard za delegirano odobravanje pristupa aplikaciji u ime korisnika                                     |
| ORM        | Object-Relational Mapping                                            | Tehnika preslikavanja tabela relacione baze u objekte programskog jezika                                   |
| PKCE       | Proof Key for Code Exchange                   | Proširenje OAuth-a koje vezuje autorizacioni kod za tajni verifikator klijenta |
| PWA        | Progressive Web App                                                  | Web aplikacija koja se može instalirati, raditi bez internet konekcije i primati push obaveštenja          |
| RAM        | Random Access Memory | Radna memorija računara |
| REST       | Representational State Transfer                                      | Arhitektonski stil web servisa zasnovan na resursima i standardnim HTTP metodama                           |
| RFC        | Request for Comments                                                 | Serija dokumenata IETF-a u kojoj se objavljuju internet standardi                                          |
| RPC        | Remote Procedure Call                         | Poziv procedure na udaljenom sistemu; JSON-RPC je njegov zapis u formatu JSON |
| SK         | — (srp. slučaj korišćenja)                                           | Oznaka slučaja korišćenja u poglavlju 4                                                                    |
| SQL        | Structured Query Language                                            | Jezik za rad sa relacionim bazama podataka                                                                 |
| TWA        | Trusted Web Activity                                                 | Mehanizam za objavljivanje progresivne web aplikacije u prodavnici Google Play                             |
| UML        | Unified Modeling Language                                            | Standardni grafički jezik za modelovanje softverskih sistema                                               |
| URL        | Uniform Resource Locator                                             | Adresa resursa na webu                                                                                     |
| UUID       | Universally Unique Identifier                                        | Globalno jedinstveni 128-bitni identifikator; koristi se kao primarni ključ tabela                       |
| VAPID      | Voluntary Application Server Identification                          | Mehanizam (RFC 8292) kojim se aplikacioni server predstavlja servisu za isporuku push poruka               |
| vCPU       | Virtual Central Processing Unit | Virtuelni procesor; jedinica naplate računarskih resursa u oblaku |
| VI         | — (srp. veštačka inteligencija)                                      | Oblast računarstva koja se bavi sistemima koji obavljaju zadatke za koje je potrebna ljudska inteligencija |
| W3C        | World Wide Web Consortium                                            | Međunarodni konzorcijum koji razvija standarde za web                                                      |
| WAI-ARIA   | Web Accessibility Initiative – Accessible Rich Internet Applications | W3C specifikacija za pristupačnost dinamičkih web aplikacija                                               |
| XSS        | Cross-Site Scripting                                                 | Napad u kome se u web stranicu ubacuje zlonamerni JavaScript kod koji se izvršava kod drugih korisnika    |
